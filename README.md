## Ringkasan Proyek (Overview)

Repositori ini merupakan *source code* portofolio interaktif milik **Christian Jhon Pranata Panjaitan** yang dirancang khusus agar nyaman dijelajahi oleh **HRD, Tech Recruiter, maupun Engineering Manager**.

Portofolio ini mendokumentasikan **7 sistem perangkat lunak end-to-end** beserta **148 tangkapan layar modul nyata** — mencakup aplikasi kecerdasan buatan yang terinstal langsung pada perangkat **IFP (Interactive Flat Panel)**, studio penyiaran langsung yang beroperasi pada infrastruktur **Video Wall & Paperless Conference System di UPN Surabaya**, ekosistem pemantauan peternakan lintas *Website & Mobile Flutter*, hingga sistem *E-Commerce* dan pengadaan korporasi *B2B*.

---

## Fitur Unggulan Portofolio (Key UX & Engineering Features)

- **Bilingual Instan (`ID` / `EN`)** — Pengalih bahasa *real-time* (Bahasa Indonesia & Bahasa Inggris) di seluruh bagian halaman, studi kasus, filter galeri, hingga modal CV.
- **Dual Comfort Theme (`Dark Bento` & `Light Comfort`)** — Mode gelap modern dan mode terang ramah mata menggunakan *semantic CSS custom properties* dengan sinkronisasi tanpa kedipan (*hydration-safe* via `useSyncExternalStore`).
- **Adaptive Multi-Platform & Multi-Portal Showcase**:
  - **Dual-Platform Studio (`Website + Mobile Flutter`)**: Menyajikan bingkai *desktop browser* untuk versi Website dan panggung vertikal **Dual-Phone Portrait Studio** tanpa terpotong (*uncropped*) untuk layar ponsel Flutter.
  - **Dual-Portal Layered Browser (`Portal User + Panel Admin`)**: Menampilkan tumpukan pratinjau jendela *Storefront Pelanggan* dan *Backoffice Admin* proporsional (`21:10`), lengkap dengan pemilih tab khusus di modal detail maupun *Fullscreen Lightbox*.
- **Interactive & Printable Executive CV Modal** — Ringkasan CV eksekutif terstruktur yang siap dicetak langsung ke PDF (`@media print`) dengan deteksi otomatis file statis `public/cv.pdf` bila tersedia.
- **Server-Side Auto Image Scanner** — Modul pemindai otomatis pada tahap *build/server* yang membaca folder proyek di `public/`, mengurutkan tangkapan layar secara cerdas (*Portal User* → *Panel Admin* → *Mobile*, *Dashboard* di awal → *Login* di akhir), dan merapikan nama file menjadi label modul yang bersih.
- **Recruiter Fast-Actions** — Salin alamat email dalam 1 klik dengan notifikasi *toast*, pembuka draf langsung ke *Gmail Web* maupun aplikasi email bawaan, serta akses cepat ke repositori kode.

## Menjalankan Proyek Secara Lokal (Getting Started)

### 1. Prasyarat
Pastikan perangkat Anda telah terinstal **Node.js 20+** dan **npm**.

### 2. Instalasi & Mode Pengembangan
```bash
# Clone repositori
git clone https://github.com/christian050104/Portfolio.git
cd Portfolio

# Instal dependensi
npm install

# Jalankan server pengembangan (otomatis membuka http://localhost:3000)
npm run dev
```

### 3. Build Produksi & Linting
```bash
# Cek kualitas kode & aturan TypeScript/ESLint
npm run lint

# Buat build produksi teroptimasi
npm run build
npm start
```

## Panduan Kustomisasi Cepat

- **Menambahkan Tangkapan Layar Baru**: Cukup masukkan gambar (`.png`, `.jpg`, `.jpeg`, `.webp`) ke folder proyek terkait di dalam `public/` (misalnya `public/DairyTrack/` atau `public/ComproAGS/`). Pemindai server `loadProjectsWithAutoImages()` akan otomatis mendeteksi, mengelompokkan (`User` / `Admin` / `Mobile`), dan membuat judul layar dari nama file.
- **Menambahkan File PDF CV Statis (Opsional)**: Simpan file CV Anda dengan nama `cv.pdf` di dalam folder `public/` (`public/cv.pdf`). Modal **Lihat CV** akan otomatis memunculkan tombol unduh langsung di samping fitur cetak PDF bawaan.
